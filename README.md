# Unit 5 Discussion: Search Algorithms

## Overview

This assignment compares linear search and binary search.

## Learning Objectives

- Implement linear search
- Implement binary search
- Compare performance
- Analyze algorithm efficiency

## Requirements

1. Test both algorithms on a small dataset.
2. Test both algorithms on a large dataset.
3. Demonstrate edge cases.
4. Analyze performance.
5. Create a real-world search scenario.


## Discussion Board Reflection

### Discussion Board Reflection

While completing this assignment, I learned how linear search and binary search work and how their performance differs depending on the size of a dataset. I decided to use a Pokémon Pokédex as my example because it provided a familiar way to demonstrate searching through records using identification numbers. I also learned how important sorting data is when using binary search because it relies on eliminating half of the remaining search area during each iteration.

One challenge I encountered was understanding how binary search determines which half of the dataset to eliminate after each comparison. I worked through this by testing different Pokémon numbers and reviewing how the search boundaries changed. I also added edge cases to make sure both algorithms handled empty lists, single-element lists, and missing values correctly.

I would use linear search when working with smaller datasets or unsorted information because it is simple to implement and does not require sorting. Binary search is more useful when working with larger, sorted datasets because it can locate information much faster. However, maintaining sorted data is an important tradeoff to consider.
